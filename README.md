## 为什么选择 StringCraft？

- **一步到位**：在任何应用中选中文字，按 `Ctrl+Alt+Space` 呼出悬浮条，点一下按钮，结果自动替换原选中内容——不用复制、粘贴、来回切换窗口。
- **纯本地、零上传**：所有转换都在本机内存中完成，不联网、不记录、无遥测。处理代码、SQL、日志、配置等敏感内容更安心。
- **极轻量**：安装包约 3MB，常驻内存约 10MB，启动快、不打扰。
- **28 种转换能力**：23 个内置转换 + 5 类自定义按钮，覆盖日常绝大多数文本处理场景。
- **完全可定制**：按钮增删排序、名称说明、字号大小、磨砂玻璃样式、主题配色、语言……按你的习惯打造专属工具条。

## 内置转换（23 个）

- **大小写**：`AB` 全大写 · `ab` 全小写 · `Ab` 每词首字母大写 · `aB` 每词首字母小写 · `Aa` 每句首字母大写
- **命名风格**：`camel` 转驼峰 · `c_` 转下划线 · `c sp` 转空格（多行按行独立转换，不会合并成一行）
- **分隔符互转**：空格 ↔ 下划线 / 换行 / 中横线（`s_` `s↵` `s-` `_s` `↵s`）· 下划线 ↔ 中横线 / 小数点（`_-` `_.` `-_` `._`）
- **文本清理**：`NoSp` 删除所有空格 · `NoNl` 删除所有换行 · `NoSym` 删除除字母、数字、空白外的所有字符
- **格式化**：`JSON` JSON 格式化 · `NumRMB` 数字转人民币大写 · `RMBNum` 人民币大写转数字

支持 Unicode：中文、英文、数字混合处理行为一致。

## 自定义按钮（5 类）

- **加后缀 / 加前缀 / 加前缀加后缀**：对每一行批量添加，保留原有换行
- **文本替换**：全文替换（区分大小写、非正则）
- **去重复行**：删除所有重复行，保留首次出现，顺序不变

自定义按钮添加后默认隐藏，勾选“显示”即出现在悬浮条，随时可改名称、说明与参数。

## 功能特性

- 🎯 **悬浮条**：无边框、置顶、自由拖动并记忆位置，下次启动回到原处
- ⌨️ **全局快捷键**：默认 `Ctrl+Alt+Space` 呼入/呼出，可在设置页自定义
- 🧰 **按钮管理**：增删、拖拽排序、显示/隐藏，工具条宽度随内容自适应
- 🎨 **外观**：磨砂玻璃按钮；马卡龙 + 莫兰迪 20 色预设与自定义背景色；透明度、字号实时调节；浅色 / 深色 / 跟随系统主题
- 🌍 **中英文切换**：界面与默认按钮文案一键切换，后续可扩展更多语言
- 📦 **配置导入导出**：换机、重装系统一键恢复个人配置
- 🔄 **检查更新**：基于 GitHub Releases 检查更新，有新版本一键跳转下载
- 🖥️ **托盘常驻**：最小化到系统托盘，随时呼出或隐藏悬浮条
- 💝 **赞助支持**：设置页扫码支持开发者

## 快速开始

1. 从 [GitHub Releases](https://github.com/Jiang-Xiaozhong/StringCraft/releases) 下载最新安装包（Windows 10/11，双击安装）。
2. 按默认快捷键 `Ctrl+Alt+Space` 呼出/隐藏悬浮条。
3. 在任意应用中选中文本，点击悬浮条上的转换按钮。
4. 转换结果自动替换选中内容；打开设置页可按自己的习惯配置按钮。
