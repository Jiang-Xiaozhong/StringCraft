# StringCraft（字符串工坊）

一个轻量、快速、完全本地运行的字符串转换工具。选中任意文本，一键完成大小写、驼峰、JSON 格式化、人民币大写等转换，并自动替换回原位置。

## 亮点

- 极轻量：安装包约 4MB，启动快，常驻托盘不占空间
- 纯本地：转换文本只在内存中处理，不上传、不记录、无遥测
- 全局快捷键：在任何应用中选中文字，按快捷键呼出悬浮条即可转换
- 自动替换：转换结果自动粘贴回原位置，并恢复原剪贴板
- 23 个内置转换：大小写、单词首字母、句子首字母、驼峰互转、分隔符替换、去重复行、JSON 格式化、人民币大写互转等
- 自定义按钮：加后缀、加前缀、文本替换、去重复行，按你的习惯打造工具条
- 高可定制：按钮名称/说明/尺寸/配色/透明度/语言都可调
- 双主题：浅色/深色/跟随系统，20 种马卡龙与莫兰迪配色
- 中英文切换：界面与默认按钮文案随语言切换
- 自动更新：基于 GitHub Releases 检查更新，可选择自动下载安装

## 使用方式

1. 下载最新安装包并安装（支持 Windows 10/11）。
2. 按默认快捷键 `Ctrl+Alt+Space` 呼出/隐藏悬浮条（可在设置中修改）。
3. 在任意应用中选中文本，点击悬浮条上的转换按钮。
4. 转换结果自动替换选中内容；也可以打开设置页按自己的习惯配置按钮。

- 除“检查更新”外，应用没有任何网络请求。

- 被转换的文本只存在于内存，不写入日志、配置或磁盘。
