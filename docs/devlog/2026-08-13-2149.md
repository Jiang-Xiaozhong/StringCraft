## 关键决策

- 单 Web 入口 + 窗口 label 分发，而非 Vite 多页：减少配置面，双窗口共用同一份构建产物。
- 悬浮条不抢焦点先用 `focus: false` 配置近似实现（F1.12）；后续如需严格 `WS_EX_NOACTIVATE` 再以原生 API 增强，避免 M1 引入额外 FFI 风险。
- 托盘 Windows 左键呼出、右键菜单；macOS 默认左键弹菜单，M5 适配时再细化。
- M1 不实现配置持久化与位置记忆（属 M4），`get_config` 返回默认配置，保证双端一致。
- `execute_button` 为占位命令，明确提示 M2 实现，避免在 M1 里夹带未经测试的转换逻辑。
