## 本次完成

- 新增 [src-tauri/src/selection.rs](src-tauri/src/selection.rs)：完整自动替换流程：
  1. 保存当前剪贴板文本（非文本内容直接放弃，避免破坏剪贴板）；
  2. 模拟 Ctrl+C 复制选中文本，等待 80ms；
  3. 读取剪贴板，与备份一致判定为未选中文本并恢复中止；
  4. 调用 M2 转换函数；
  5. 写入转换结果，模拟 Ctrl+V 粘贴，等待 80ms；
  6. 按配置恢复原剪贴板（默认开启）。
- 选中文本超过 1MB 时不自动替换，仅将结果写入剪贴板并提示手动粘贴。
- 新增依赖：`arboard 3.6.1`（剪贴板）、`enigo 0.6.1`（键盘模拟）、`windows 0.61`（仅 Windows，用于窗口扩展样式）。
- `execute_button` 改为异步命令：传入文本时直接转换（调试/测试用），未传文本时在后台线程执行完整替换，避免阻塞 UI。
- 前端气泡改为展示 Rust 返回的实际提示（成功/失败/降级文案）。

## 关键决策

- 复制/粘贴等待固定 80ms，落在需求 3.1 的 50~100ms 区间，后续可在设置页暴露为高级选项（M4）。
- “粘贴失败”仅能可靠捕获 SendInput/enigo 层错误；目标应用收到按键但不响应的情况无法可靠检测，先用 API 层失败 + 剪贴板恢复兜底。
- 非文本剪贴板（图片/文件）在操作前即放弃，避免任何模拟按键破坏用户剪贴板。
- 剪贴板恢复失败时不崩溃，转换结果保留在剪贴板并如实提示。
- 隐私：整个流程文本只存在于内存，不写日志/配置/磁盘。
- 配置持久化采用 serde_json 直写 JSON（未使用 tauri-plugin-store）：Rust 侧需要同步访问配置、损坏备份与原子写，直接管理文件更可控；plugin-store 仍保留注册备用。
- 快捷键冲突在设置页保存时明确提示并回滚；启动时注册失败仅打印日志不阻断启动（托盘仍可用）。
- 配置路径固定为 StringCraft 目录而非 bundle identifier 目录，与需求 6.3 保持一致。
