# 2026-08-15 0956 开发日志

## 机器

- Windows

## 任务

实现需求 v0.7 中的 Windows 视觉/交互打磨：修复背景透明度与主题不生效，新增背景颜色设置、磨砂玻璃按钮、默认英文按钮名、工具条自由拖动与位置记忆、按钮显示/隐藏、工具条宽度自动调整，以及设置页拖拽排序与布局优化。

## 本次完成

- Rust 配置模型扩展：
  - `AppConfig` 新增 `backgroundColor`、`backgroundColorDark`、`position`；
  - `TransformButton` 新增 `visible`，旧配置缺失时默认 `true`；
  - 20 个默认按钮名改为英文/缩写（`AB`、`ab`、`Ab`、`aB`、`camel`、`NoSym` 等），说明保持中文；
  - 新增 `is_hex_color` / `normalize_color` 校验颜色，`opacity` 范围收紧为 20~100。
- 新增 Tauri 命令 `update_float_bar_position`，拖动结束后持久化悬浮条位置，且不触发 `config-changed` 回跳。
- 悬浮条：
  - 读取配置后按可见按钮数动态计算窗口宽度，超出屏幕可用宽度时按钮缩至最小 36px；
  - 支持自由拖动并记忆位置，首次启动/未保存位置时默认右上角；
  - 启动恢复保存位置并按当前显示器归位；
  - 背景颜色、主题、透明度即时生效，深色主题使用深色变体；
  - 按钮改为半透明磨砂玻璃样式。
- 设置页：
  - 背景颜色区：10 个马卡龙预设 + 1 个自定义颜色按钮；
  - 名称/说明输入框统一固定宽度，英文转换标识用分隔线单独分组；
  - 每个按钮增加“显示/隐藏”开关，隐藏项置灰保留；
  - 取消上/下箭头，改为拖拽手柄跨行排序；
  - 按钮列表改为单列，拖拽与视觉反馈更清晰。
- 全局样式改为 `data-theme` 控制浅色/深色，替代仅依赖 `prefers-color-scheme` 的方式。

## 关键决策

- 位置使用独立命令保存，避免复用 `save_config` 后 `config-changed` 导致悬浮条被刷新回默认位置。
- 自定义颜色只提供一个浅色选择器，深色变体由前端 `darkenHex` 自动生成并保存。
- 工具条高度按“实际渲染的可见行数”计算，隐藏按钮后空白行同步收起，视觉更紧凑。
- 默认按钮名只影响新配置与“恢复默认按钮”，不会覆盖用户已有的自定义名称。
