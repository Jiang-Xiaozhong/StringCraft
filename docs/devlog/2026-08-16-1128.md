## 任务

实现 M6（v0.12）新增需求：尺寸范围调整、设置页禁止右键、莫兰迪色系、恢复默认确认框、配置导出/导入、3 个新转换按钮。

## 本次完成

- 按钮尺寸范围：
  - 宽度范围改为 20~200px、高度范围改为 10~80px；
  - 设置页输入框、Rust 校验与悬浮条布局计算同步更新。
- 设置页禁止右键：设置页根节点屏蔽 `contextmenu`。
- 莫兰迪色系：新增 10 个莫兰迪预设（浅色/深色各一），设置页分“马卡龙色系 / 莫兰迪色系”两组展示。
- 恢复默认确认框：点击“恢复默认按钮”弹出自定义确认框，确认后才还原 23 个内置按钮。
- 配置导出/导入：
  - 新增 `tauri-plugin-dialog` 与 `@tauri-apps/plugin-dialog`；
  - 设置页新增“导出配置 / 导入配置”按钮；
  - Rust 新增 `export_config_to` / `import_config_from` 命令，导入前校验、失败提示。
- 新增 3 个转换按钮：
  - `JSON`：JSON 格式化（2 空格缩进、保持字段顺序，非法输入原样返回）；
  - `NumRMB`：数字转人民币大写（支持 0~999999999999.99）；
  - `RMBNum`：人民币大写转数字（支持元/角/分/整写法）。
  - 默认按钮由 20 个增至 23 个，默认布局更新为 3 行（10+10+3），默认窗口高度同步调整。

## 关键决策

- JSON 格式化启用 `serde_json` 的 `preserve_order` 特性，保证字段顺序不变。
- 人民币转换采用字符串解析避免浮点精度问题；非法输入原样返回。
- 导出/导入通过系统文件对话框选择路径，文件读写仍在 Rust 侧完成。
