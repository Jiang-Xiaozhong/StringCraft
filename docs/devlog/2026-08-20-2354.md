## 关键决策

- 下载更新改走浏览器：应用内下载链路存在“下载完成后无安装入口/下载不可用”的问题，跳转 GitHub Releases 页面最可靠、零额外依赖，且与“发布源只有 GitHub”的现状一致；自动更新开关（默认关闭）的在应用内下载行为暂未改动。
- 隐藏 BUG 根因：Tauri 已知问题（#14088 同型）——窗口长时间 `hide()` 后，Windows 可能回收 WebView2 页面进程，再次显示时界面仍在但点击无响应（IPC 无响应、无气泡），与用户“点按钮没反应、剪贴板没内容”的现象吻合。修复采用“不真正隐藏、移出屏幕 + 点击穿透”的保活方案，实测隐藏期间 WebView2 进程数保持不变。
- 隐藏/呼出用后端统一管理（`FloatBarState.logical_visible`），前端隐藏按钮与托盘/快捷键/单实例入口共用同一套逻辑，避免状态不一致。
- macOS 暂不改变原有 hide/show 行为（该问题为 Windows WebView2 特性，macOS 侧待 M8 实机验证后再定）。
