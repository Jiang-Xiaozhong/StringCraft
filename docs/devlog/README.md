# 开发日志

每台电脑上的 Codex 在每次开工前先读本目录中文件名最新的日志接续上下文，收尾时新建自己的日志并随代码提交推送。规则详见仓库根目录 [AGENTS.md](../../AGENTS.md)。

## 文件命名

`YYYY-MM-DD-HHmm.md`，`HHmm` 为本次开工时的本地时间。这样两台电脑即使同一天工作也不会写同一文件产生冲突。

## 日志模板

```markdown
# 开发日志 YYYY-MM-DD HH:mm

- 机器：Windows / macOS
- 任务：一句话描述本次目标

## 本次完成

- 改了哪些内容、涉及哪些文件

## 关键决策

- 为什么这样做、已确认的结论

## 验证

- 测试 / 构建 / 运行结果

## 当前状态与下一步

- 未完成部分与下一步计划

## 遗留问题

- 已知坑、临时绕过、待确认事项
```
