# StringCraft Windows 回归测试清单

适用版本：M7（Windows 10/11）。测试环境建议覆盖 100% 与 150% DPI。

## 启动与常驻

- [x] 双击 EXE 启动无黑窗、无崩溃，悬浮条显示在右上角
- [x] 托盘图标常驻，左键呼出悬浮条，右键菜单包含“呼出悬浮条 / 隐藏悬浮条 / 打开设置 / 退出”
- [x] 第二次启动（快捷方式）只呼出已有悬浮条，不创建新实例

## 自动替换

- [x] 在记事本/浏览器/IDE 选中文本，点击按钮后自动替换，原剪贴板内容恢复
- [x] 未选中文本时提示“未检测到选中文本”，不改变剪贴板
- [x] 剪贴板含图片/文件时放弃自动替换并提示
- [x] 转换结果为空的按钮（如删除全部）正常清空选中内容

## 悬浮条

- [x] 自由拖动并记忆位置，重启后恢复
- [x] 右侧边缘拖动调整宽度，按钮自动换行，高度自适应
- [x] 设置/隐藏按钮：单行时横排，多行时竖排
- [x] 隐藏悬浮条按钮生效，托盘仍常驻；托盘“隐藏悬浮条”同样生效
- [x] 右键悬浮条不弹系统菜单
- [x] 按钮悬停约 500ms 显示说明气泡，紧贴鼠标且完整显示在窗口内

## 设置页

- [x] 快捷键录制、恢复默认、冲突提示
- [x] 按钮增删、拖拽排序、显示/隐藏、名称/说明/参数修改，悬浮条即时生效
- [x] 添加自定义按钮（加后缀/加前缀/文本替换/去重复行）并默认隐藏，勾选后显示
- [x] 恢复默认按钮弹确认框，确认后还原 23 个内置按钮（前 10 个显示）
- [x] 宽度/高度/字号/透明度滑块实时反馈到悬浮条
- [x] 背景颜色：马卡龙 + 莫兰迪共 20 个预设与自定义颜色即时生效
- [x] 深色主题下下拉框/控件配色正常
- [x] 配置导出/导入：导出 JSON，导入合法配置生效、非法配置提示
- [x] 中文/English 切换后界面文案与默认按钮说明同步切换
- [x] 打赏默认显示，可隐藏并持久化
- [x] 点系统关闭按钮后，再点设置按钮可重新打开
- [x] 设置页右键不弹系统菜单

## 更新

- [x] 手动“检查更新”：有新版本提示、无新版本提示“当前版本已是最新”
- [x] 自动检查更新开关与自动更新开关生效
- [x] 离线时检查更新静默失败，不影响使用

## 其他

- [x] 开机自启开关生效
- [x] 调试日志开关：开启后日志文件生成且不含被转换文本
- [x] 安装包体积 ≤ 15MB，安装/卸载正常
