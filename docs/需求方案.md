# StringCraft（字符串工坊）需求方案

> 版本：v0.16（修订）  
> 日期：2026-08-16  
> 状态：M6、M7 已完成；M8 macOS 适配进行中；M9 双平台发布待开始

---

## 1. 项目概述

StringCraft 是一款跨平台（Windows 10/11、macOS）的轻量级字符串处理工具。用户在任何应用中选中文字，通过全局快捷键或双击快捷方式呼出悬浮条，点击按钮即可对选中文本执行转换，并自动替换回原位置。

产品核心诉求：

- 双平台：Windows 10/11、macOS
- 双页面：悬浮条（常驻、全局快捷键呼入呼出）+ 设置页面
- 小巧：安装包小、内存占用低、启动快
- 纯本地：除“检查更新”外无网络请求；更新检查仅访问 GitHub Releases，不上传任何数据、无遥测

## 2. 产品范围

### 2.1 本期包含

- 悬浮条窗口（无边框、置顶、可拖动、位置记忆）
- 全局快捷键呼入/呼出悬浮条
- 快捷方式 / 任务栏 / Dock 图标呼入悬浮条
- 自动替换：复制选中文本 → 转换 → 粘贴回去
- 23 个默认转换按钮（20 个原有转换 + JSON 格式化、数字转人民币大写、人民币大写转数字）
- 自定义按钮：加后缀、加前缀、文本替换、去重复行
- 设置页：快捷键设置、按钮增删/排序/名称与说明自定义、按钮尺寸设置
- 设置页：悬浮条背景颜色（马卡龙 + 莫兰迪两套色系预设 + 自定义）与背景透明度
- 设置页禁止右键菜单
- 设置配置导出 / 导入
- 检查更新与自动更新（基于 GitHub Releases）
- 中英文切换（后续可扩展更多语言）
- 设置页打赏：展示支付宝/微信收款码，默认显示、可隐藏
- 按钮磨砂玻璃样式，视觉上悬浮于工具条背景之上
- 工具条自由拖动并记忆位置，下次启动恢复到上次位置
- 按钮显示/隐藏控制，隐藏按钮不出现在悬浮条但保留在配置中
- 工具条宽度由边缘拖动调整，按钮按当前宽度自动换行，高度自动计算
- 工具条禁用右键菜单
- 工具条设置按钮下方提供“隐藏悬浮条”按钮，隐藏后托盘图标保持常驻
- 托盘右键菜单提供“隐藏悬浮条”
- 设置页按钮扁平列表拖拽排序，替代上/下箭头按钮
- 配置持久化（本地 JSON）
- 托盘图标（Windows 通知区域 / macOS 菜单栏）
- 占位应用图标（正式图标后续设计）
- macOS 签名与公证（已具备 Apple Developer 账号）
- Windows / macOS 双平台打包

- 富文本/图片剪贴板内容的完整备份与恢复（v1 仅纯文本）

## 3. 核心交互流程

### 3.1 自动替换主流程

1. 用户在任意应用（文本编辑器、浏览器、IDE 等）中选中一段文字。
2. 用户通过以下任一方式呼出悬浮条：
   - 按全局快捷键；
   - 双击桌面/开始菜单/程序坞中的 StringCraft 快捷方式（应用已运行时，直接呼出已有悬浮条，不创建新实例）；
   - 悬浮条已常驻显示时直接使用。
3. 用户点击悬浮条上的转换按钮。
4. 应用执行：
   - 保存当前剪贴板内容（用于之后恢复；若检测到非文本内容，按 3.2 降级处理）；
   - 模拟 `Ctrl+C`（macOS 为 `Cmd+C`）复制选中文本；
   - 等待 50~100ms 后读取剪贴板；
   - 若读取结果与备份一致（说明未复制到新内容），判定为未选中文本，中止并提示（见 3.2）；
   - 对文本执行对应转换；
   - 将转换结果写入剪贴板；
   - 模拟 `Ctrl+V`（macOS 为 `Cmd+V`）粘贴替换；
   - 等待 50~100ms 后恢复原剪贴板内容。
5. 按钮给出短暂的高亮/动画反馈，表示执行完成。

### 3.2 异常与降级处理

| 场景 | 处理方式 |
| --- | --- |
| 剪贴板为空 / 未检测到选中文本 | 提示“未检测到选中文本”，恢复剪贴板，不粘贴 |
| 复制后剪贴板与备份一致 | 判定为未选中文本，提示后中止，恢复剪贴板（选中内容与原剪贴板完全相同时可能误判，可接受） |
| 目标应用不支持模拟粘贴（如终端、密码框） | 转换结果保留在剪贴板，提示“已复制到剪贴板”，由用户手动粘贴 |
| 选中文本过大（超过阈值，如 1MB） | 不执行自动替换，仅将结果放入剪贴板并提示 |
| 粘贴失败 | 不崩溃，提示失败原因，剪贴板恢复原内容 |
| 快捷键注册冲突 | 设置页给出冲突提示，要求更换组合键 |
| 剪贴板含图片/文件等非文本内容 | 放弃自动替换并提示，避免破坏用户剪贴板 |
| 目标应用以管理员身份运行（Windows） | 需 StringCraft 以管理员身份运行，否则无法注入；作为已知限制提示 |
| 配置文件损坏 | 自动备份损坏文件，恢复默认配置，不崩溃 |
| 转换结果为空字符串 | 视为正常（等于清空选中内容），正常粘贴，不提示失败 |

## 4. 功能需求

## 4.1 悬浮条

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F1.1 | 常驻悬浮显示 | 无边框、置顶、不抢焦点；应用运行期间常驻显示（开机自启默认关闭，可在设置页开启） |
| F1.2 | 全局快捷键呼入/呼出 | 默认 `Ctrl+Alt+Space`（Win）/ `Cmd+Option+Space`（macOS），可在设置页修改 |
| F1.3 | 拖动与位置记忆 | 悬浮条可自由拖动到任意位置；拖动结束后的位置保存到配置，下次启动恢复该位置；运行中不自动复位到默认位置 |
| F1.4 | 设置按钮 | 悬浮条固定包含一个设置按钮（不可删除、不可排序），点击打开设置窗口 |
| F1.5 | 快捷按钮区 | 按钮由设置页配置：增删、显示/隐藏、拖拽排序、名称与说明自定义 |
| F1.6 | 工具条宽度调整 | 用户可用鼠标按住工具条边缘拖动，任意调整工具条宽度；调整结果保存并记忆；不设固定行数 |
| F1.7 | 自动换行 | 按钮按当前工具条宽度自动换行，不限制每行按钮数量和总行数；按钮保持设置宽度，空间不足时自动换到下一行 |
| F1.8 | 按钮尺寸 | 全局统一：宽度、高度、字号；不支持单个按钮单独调尺寸 |
| F1.9 | 超宽与超窄处理 | 工具条宽度有最小宽度，确保至少容纳 1 个按钮；按钮不自动缩小、不做横向滚动，空间不足时自动换行 |
| F1.10 | 执行反馈 | 点击按钮后按钮短暂高亮，表示执行完成或失败 |
| F1.11 | 快捷方式呼入 | 双击 StringCraft 快捷方式（Windows：桌面/开始菜单 `.lnk`；macOS：`.app`）时，若应用未运行则启动并显示悬浮条；若已运行则只呼出悬浮条，不创建新实例 |
| F1.12 | 不抢焦点 | 点击悬浮条不夺取原应用焦点（Windows 使用 `WS_EX_NOACTIVATE`，macOS 使用非激活面板），保证自动替换仍作用于原应用 |
| F1.13 | 初始位置与越界归位 | 首次启动或未保存位置时默认显示在屏幕右上角；用户可自由拖动到任意位置并记忆；保存的位置超出当前屏幕时自动归位到屏幕内 |
| F1.14 | 按钮名称长度 | 按钮名称建议 ≤ 8 个字符，超出时自动截断并用省略号显示；悬停气泡可查看说明或完整名称（见 F1.15） |
| F1.15 | 按钮说明气泡 | 鼠标悬停在按钮上约 500ms 后弹出气泡显示按钮说明；未填写说明时回退显示完整名称，避免名称截断看不清；气泡紧贴鼠标并随鼠标移动，完整显示在悬浮条窗口内，不超出边框 |
| F1.16 | 按钮磨砂玻璃样式 | 按钮采用半透明磨砂玻璃效果，配合模糊、细边框和阴影，视觉上悬浮于工具条背景之上；hover / active 状态清晰可辨 |
| F1.17 | 背景颜色设置 | 设置页提供 10 个马卡龙色系预设颜色，并提供自定义颜色按钮；所选颜色即时应用到悬浮条背景 |
| F1.18 | 主题与背景联动 | `light` / `dark` / `system` 主题必须实际生效；深色主题下使用当前背景色对应的深色变体，背景透明度同样生效；设置页下拉框等原生控件随主题切换配色 |
| F1.19 | 按钮显示/隐藏 | 每个转换按钮可单独设为隐藏；隐藏按钮不显示在悬浮条上、不参与自动换行计算，但保留在设置页列表与配置中，可随时恢复显示 |
| F1.20 | 工具条宽度记忆 | 用户拖动边缘调整后的宽度保存到配置，下次启动恢复；高度根据可见按钮数和当前宽度自动计算，不随按钮数量自动改变宽度 |
| F1.21 | 拖拽排序 | 设置页按钮以扁平列表展示，取消上/下箭头按钮，改为鼠标按住后拖到任意位置，松开后即时保存 |
| F1.22 | 默认布局 | 首次打开时 23 个默认按钮按固定顺序全部保留在管理列表；前 10 个默认显示（排成 1 行，宽度恰好容纳 10 个按钮），其余 13 个默认隐藏；默认单行时设置按钮与隐藏按钮横排显示；用户后续调整会覆盖默认值 |
| F1.23 | 禁用右键 | 工具条区域禁用系统右键菜单，右键点击不弹出浏览器/系统菜单 |
| F1.24 | 隐藏按钮 | 设置按钮下方提供“隐藏悬浮条”按钮；点击后工具条隐藏，托盘图标保持常驻，可通过托盘或快捷键再次呼出；按钮只有一行时设置与隐藏按钮横排显示，多行时上下竖排 |
| F1.25 | 托盘隐藏菜单 | 托盘图标右键菜单包含“隐藏悬浮条”项，点击后隐藏工具条但不退出应用 |

## 4.2 设置页面

设置页为独立窗口，从悬浮条的设置按钮打开。所有修改即时生效并持久化。

- 设置页禁止右键菜单：右键点击不弹出系统菜单。

### 4.2.1 快捷键设置

- 修改“呼入/呼出悬浮条”的全局快捷键；
- 支持“录制”方式设置（点击输入框后直接按目标组合键）；
- 支持恢复默认快捷键；
- 快捷键注册失败时给出冲突提示。

### 4.2.2 按钮管理

- 以扁平列表展示全部按钮，不再按固定行分组；
- 添加按钮：选择未使用的内置转换功能（23 个内置功能），自定义按钮名称（默认显示功能名）与按钮说明（选填）；
- 添加按钮支持自定义类型：加后缀、加前缀、文本替换、去重复行；
  - 加后缀 / 加前缀：需填写目标文本（追加/前置的内容）；
  - 文本替换：需填写“被替换文本”和“替换为文本”两个输入框；
  - 去重复行：无需额外参数；
- 自定义按钮添加后默认隐藏（`visible=false`），保留在按钮管理列表，用户勾选“显示”后出现在悬浮条；
- 自定义按钮支持修改名称、说明与参数；
- 删除按钮；
- 编辑按钮名称与说明（说明选填，用于悬浮气泡展示）；
- “名称”输入框与“说明”输入框宽度统一；
- 每个列表项右侧固定“显示”开关与“删除”按钮，靠右对齐；
- 每个按钮提供“显示/隐藏”开关；隐藏按钮不显示在悬浮条上，但在设置页保留并置灰，可随时恢复显示；
- 调整按钮顺序：取消上/下箭头按钮，改为鼠标按住后拖到任意位置，松开后即时保存；
- 取消行数设置，不限制每行按钮数量和总行数；
- 工具条宽度由用户在悬浮条边缘拖动调整；按钮按当前宽度自动换行，设置页无需维护行数；
- “恢复默认按钮”一键还原 23 个内置按钮；点击后弹出确认框，用户确认后才执行。
- 每个内置功能有固定 id（如 `upper`、`lower`），与名称/说明解耦：修改名称或说明不影响转换逻辑。

### 4.2.3 外观设置

- 按钮宽度（20~200px）、按钮高度（10~80px）、按钮字号（10~24px）均使用拖动滑块设置；
- 悬浮条背景不透明度（范围 0%~100%，默认 100%）；
  - 调整后即时生效并持久化；
- 外观实时反馈：宽度、高度、字号、透明度在滑动时即时同步到悬浮条，并持久化。
- 背景颜色：提供 10 个马卡龙色系 + 10 个莫兰迪色系共 20 个预设颜色，并提供自定义颜色按钮；
  - 选中颜色即时应用到悬浮条背景；
  - 深色主题下使用所选颜色的深色变体（见 4.2.3 颜色表）；
  - 自定义颜色同样保存浅色/深色两个变体。
- 主题：`system` / `light` / `dark` 三种模式；
  - 切换后即时生效并持久化；
  - 设置页下拉框等原生控件随主题切换配色。
- 按钮磨砂玻璃样式：半透明背景 + 模糊 + 细边框 + 阴影，视觉上悬浮于工具条背景之上；
- 设置按钮与隐藏悬浮条按钮为正方形，边长跟随按钮高度设置；调整按钮高度时同步变化；
- 所有按钮统一变化。
- 输入范围校验：宽度 20~200px、高度 10~80px、字号 10~24px，超出时提示并取边界值。

### 4.2.4 通用设置

- 开机自启（默认关闭，可在设置页开启/关闭）；
- 剪贴板恢复开关（默认开启）；
- 失败提示方式：默认气泡提示，要求简洁、清晰、美观（悬浮条内圆角气泡，自动消失，不抢焦点）；
- 自动替换延迟（高级选项，默认值即可）。
- 调试日志开关（默认关闭）；开启后把运行事件写入本地日志文件，日志不含被转换的文本。
- 设置页底部展示反馈邮箱：有任何问题或建议请反馈至 `jxzlh1208@163.com`（可点击发送邮件）。
- 配置导入/导出：支持把当前设置导出为 JSON 文件，也支持导入 JSON 配置；导入前校验，非法配置拒绝并提示，导入后即时生效并持久化。
- 语言选择：中文 / English，默认跟随系统或中文（实现时确定），界面与默认按钮文案随语言切换。
- 自动检查更新（默认开启）与自动更新（默认关闭），详见 4.8。
- 打赏显示开关：默认显示，可点击隐藏并持久化，详见 4.10。

## 4.3 默认按钮与转换规则

以下是内置的 23 个转换按钮。默认按钮名固定为简单英文/缩写，顺序固定；用户可删除、改名称/说明、排序。
23 个按钮默认全部保留在按钮管理列表，顺序见下表；前 10 个默认显示，其余 13 个默认隐藏，可随时在设置页恢复显示。
默认工具条宽度恰好容纳 10 个按钮与横排的设置/隐藏按钮，因此默认显示为 1 行。

统一约定：

- “单词”默认以空白、下划线、中横线、小数点、换行作为边界；
- 连续分隔符不做合并（已确认，如两个空格替换为两个下划线）；
- 转换后无变化时原样返回；
- 全部规则对 Unicode 文本有效（中文、英文、数字混合时行为一致）。

| # | 默认按钮名 | 转换规则 | 示例 | 默认显示 |
| --- | --- | --- | --- | --- |
| 1 | `JSON` | JSON 格式化 | 输入合法 JSON 时按 2 空格缩进格式化输出，字段顺序保持不变；非法 JSON 原样返回 | 是 |
| 2 | `camel` | 按下划线/空格分词：首词转小写，后续词首字母大写、其余小写，删除分隔符 | `hello_world`、`hello world` → `helloWorld` | 是 |
| 3 | `c_` | 大小写交界处分词，全部转小写，下划线连接 | `helloWorld` → `hello_world`；`HelloWorld` → `hello_world` | 是 |
| 4 | `c sp` | 大小写交界处分词，全部转小写，空格连接（已确认） | `helloWorld` → `hello world`；`HelloWorld` → `hello world` | 是 |
| 5 | `aB` | 每个单词首字母小写，其余字母大写，分隔符保留 | `hello world` → `hELLO wORLD` | 是 |
| 6 | `AB` | 所有字母转大写 | `hello world` → `HELLO WORLD` | 是 |
| 7 | `ab` | 所有字母转小写 | `Hello World` → `hello world` | 是 |
| 8 | `NoSym` | 删除除 Unicode 字母、数字、空白外的所有字符 | `hello, world!` → `hello world` | 是 |
| 9 | `s_` | 空格字符替换为下划线 | `hello world` → `hello_world` | 是 |
| 10 | `s↵` | 空格替换为换行 | `a b` → `a` + 换行 + `b` | 是 |
| 11 | `s-` | 空格替换为中横线 | `hello world` → `hello-world` | 否 |
| 12 | `_s` | 下划线替换为空格 | `hello_world` → `hello world` | 否 |
| 13 | `↵s` | 换行（含 CRLF）替换为空格 | `a` + 换行 + `b` → `a b` | 否 |
| 14 | `NoSp` | 删除所有空格字符（半角/全角），保留换行 | `h e l l o` → `hello` | 否 |
| 15 | `NoNl` | 删除所有换行（LF/CRLF），保留空格 | `a` + 换行 + `b` → `ab` | 否 |
| 16 | `_-` | 下划线替换为中横线 | `hello_world` → `hello-world` | 否 |
| 17 | `_.` | 下划线替换为小数点 | `hello_world` → `hello.world` | 否 |
| 18 | `-_` | 中横线替换为下划线 | `hello-world` → `hello_world` | 否 |
| 19 | `._` | 小数点替换为下划线 | `hello.world` → `hello_world` | 否 |
| 20 | `Aa` | 每个句子首字母大写，其余字母小写；以 `.` `!` `?` 为句子边界 | `hello world. how are you` → `Hello world. How are you` | 否 |
| 21 | `Ab` | 每个单词首字母大写，其余字母小写，分隔符保留 | `hello WORLD` → `Hello World`；`THINK` → `Think`；`hello_world` → `Hello_World` | 否 |
| 22 | `NumRMB` | 数字转人民币大写 | 支持 0~999999999999.99；`1234.56` → `壹仟贰佰叁拾肆元伍角陆分`，`0` → `零元整`；非法输入原样返回 | 否 |
| 23 | `RMBNum` | 人民币大写转数字 | 支持“元/角/分/整、零壹贰叁肆伍陆柒捌玖、拾佰仟万亿”写法；`壹仟贰佰叁拾肆元伍角陆分` → `1234.56`；非法输入原样返回 | 否 |

## 4.4 全局快捷键

- 仅支持一个“呼入/呼出”快捷键（v1）；
- 默认快捷键（已确认）：Windows `Ctrl+Alt+Space`，macOS `Cmd+Option+Space`；配置中统一用 `Ctrl` 表示主修饰键，macOS 自动映射为 `Cmd`；
- 必须包含至少一个修饰键（Ctrl / Alt / Shift / Cmd / Option 任意组合）；
- 快捷键在应用后台运行时依然有效（应用常驻后台）；
- 注册失败时提示冲突，不静默失败。

## 4.5 快捷方式呼入

- 双击 StringCraft 快捷方式（Windows：桌面/开始菜单 `.lnk`；macOS：Applications/Launchpad/Dock 中的 `.app`）即“呼入”悬浮条；
- 应用未运行时：正常启动，启动完成后直接显示悬浮条；
- 应用已运行时：第二次启动立即退出，由已运行实例呼出悬浮条（依赖单实例机制）；
- 双击快捷方式的行为固定为“呼出/显示”，不做显隐切换（已确认，避免用户无法预估状态）；
- Windows 任务栏图标、macOS Dock 图标点击时也执行相同“呼出”动作（已确认，默认开启）。

## 4.6 自动替换（核心链路）

- 平台实现：Windows 使用 SendInput；macOS 使用 CGEvent；
- macOS 首次使用时引导用户开启“辅助功能”权限，提供一键打开系统设置；
- macOS 启动时和首次使用时检测“辅助功能”权限，未授权时引导开启，设置页显示权限状态；
- Windows 无需额外权限；若目标应用以管理员身份运行，StringCraft 需以管理员身份运行（已知限制）；
- 操作完成后恢复用户原剪贴板内容（文本格式 v1 仅恢复纯文本，富文本后续；非文本内容按 3.2 降级处理）；
- 转换逻辑放在 Rust 核心层，保证跨平台行为一致，并有单元测试覆盖。
- 执行期间忽略重复点击（按钮短暂禁用，单次操作完成后恢复），防止多重粘贴；
- 转换结果允许为空字符串（等于清空选中内容），不视为失败；
- 隐私：转换文本仅在内存中处理，不写入日志、配置或磁盘。

## 4.7 托盘图标（Windows 通知区域 / macOS 菜单栏）

- 应用常驻托盘/菜单栏图标，用于快捷操作与退出；
- Windows：左键单击托盘图标呼出悬浮条；右键菜单包含“呼出悬浮条 / 隐藏悬浮条 / 打开设置 / 退出”；
- macOS：点击菜单栏图标弹出菜单，包含“呼出悬浮条 / 打开设置 / 退出”；
- 退出后：托盘图标消失，全局快捷键与自动替换全部停止。
- 右键“退出”直接退出应用，不弹二次确认（轻量工具定位，后续可加）。

## 4.8 检查更新与自动更新

- 发布源：GitHub Releases（`Jiang-Xiaozhong/StringCraft`），以 release tag 版本号（如 `v0.1.0`）与当前应用版本比较。
- 手动检查：设置页提供“检查更新”按钮，点击后查询 GitHub 最新 Release：
  - 有新版本：弹窗展示新版本号与更新说明，提供“去下载/更新”入口；
  - 已是最新：提示“已是最新版本”；
  - 网络失败：提示“检查更新失败，请稍后重试”，不影响正常使用。
- 定时检查：默认开启，应用启动后延迟检查一次，并每 24 小时自动检查一次；仅在发现新版本时提示。
- 自动更新（用户选择）：
  - 设置页“自动更新”开关（默认关闭）；
  - 开启后检测到新版本自动下载对应平台的安装包，下载完成提示用户确认安装（Windows 运行 NSIS 安装包）；
  - 关闭时仅提示有新版本，由用户手动下载。
- 隐私：更新检查仅访问 GitHub Releases API，不上传任何数据；检查失败静默降级，离线可正常使用。
- Windows 优先实现；macOS 自动更新随 M9（macOS 适配）一并处理。

## 4.9 多语言（中英文切换）

- 可扩展性：语言包结构支持后续新增语言（如 `ja-JP`）。

## 6. 技术架构

### 6.1 技术选型

- 框架：**Tauri 2**（Rust 后端 + 系统 WebView）
- 前端：**Svelte + TypeScript + Vite**（轻量、无重型运行时）
- 快捷键：`tauri-plugin-global-shortcut`
- 单实例与快捷方式呼入：`tauri-plugin-single-instance`
- 开机自启：`tauri-plugin-autostart`
- 剪贴板：`arboard` 或 `tauri-plugin-clipboard-manager`
- 键盘模拟：`enigo`（Windows SendInput / macOS CGEvent）
- 配置存储：`tauri-plugin-store`（JSON）
- 打包：Windows NSIS / MSI，macOS DMG；GitHub Actions 双平台构建

### 6.2 模块划分

```text
StringCraft
├── 前端（Svelte）
│   ├── 悬浮条窗口    // 无边框、置顶
│   └── 设置窗口      // 快捷键、按钮管理、外观
├── Rust 核心
│   ├── transform.rs  // 23 个纯函数转换 + 单元测试
│   ├── selection.rs  // 复制 → 转换 → 粘贴 → 恢复剪贴板
│   ├── hotkey.rs     // 全局快捷键注册
│   ├── config.rs     // 配置读写与校验
│   └── commands.rs   // Tauri IPC 命令
└── 平台适配
    ├── windows.rs    // SendInput
    └── macos.rs      // CGEvent + 辅助功能权限
```

### 6.3 配置数据结构（草案）

```json
{
  "version": 1,
  "hotkey": "Ctrl+Alt+Space",
  "toolbarWidth": 720,
  "buttonWidth": 60,
  "buttonHeight": 30,
  "fontSize": 12,
  "opacity": 96,
  "theme": "system",
  "backgroundColor": "#DCEBFA",
  "backgroundColorDark": "#27384A",
  "position": null,
  "autoStart": false,
  "restoreClipboard": true,
  "language": "zh-CN",
  "autoCheckUpdate": true,
  "autoUpdate": false,
  "showDonation": true,
  "buttons": [
    { "id": "upper", "name": "AB", "transform": "upper", "description": "所有字母转为大写", "visible": true },
    { "id": "lower", "name": "ab", "transform": "lower", "description": "所有字母转为小写", "visible": true },
    { "id": "custom-1", "name": "加后缀", "transform": "custom", "description": "每行末尾追加：!!!", "visible": false, "customType": "append-suffix", "param1": "!!!", "param2": null }
  ]
}
```

配置保存在系统应用数据目录：

- Windows：`%APPDATA%\StringCraft\config.json`
- macOS：`~/Library/Application Support/StringCraft/config.json`

新增字段说明：

- `toolbarWidth`：工具条窗口宽度（逻辑像素），由用户在悬浮条边缘拖动设置；默认值恰好容纳 10 个默认宽度按钮；
- `position`：工具条上次保存的屏幕位置（物理像素），未保存时为 `null`；
- `opacity`：悬浮条背景不透明度，范围 0~100；
- `backgroundColor`：浅色模式背景色（预设或自定义颜色）；
- `backgroundColorDark`：深色模式背景色（预设对应深色变体，自定义颜色保存自动生成的深色变体）。
- 按钮 `visible`：是否显示在悬浮条上；`false` 时仅在设置页管理列表中保留。
- 按钮 `customType`：自定义按钮类型（`append-suffix` / `prepend-prefix` / `replace-text` / `remove-duplicate-lines`），内置按钮为 `null`；
- 按钮 `param1`：自定义参数 1（后缀/前缀文本，或文本替换的“被替换文本”）；
- 按钮 `param2`：自定义参数 2（文本替换的“替换为文本”，其他类型为 `null`）。
- `language`：界面语言（`zh-CN` / `en-US`，后续可扩展更多语言）；
- `autoCheckUpdate`：是否自动检查更新（默认 `true`）；
- `autoUpdate`：是否自动更新（默认 `false`，用户选择）；
- `showDonation`：设置页是否显示打赏（默认 `true`）。

说明：原 `rows` 行数字段已移除，工具条高度由 `toolbarWidth`、可见按钮数和按钮宽度自动计算。

## 8. 已确认决策

| # | 决策点 | 确认结果 |
| --- | --- | --- |

| 工具条隐藏按钮 | 点击设置按钮下方的隐藏按钮，工具条隐藏但托盘图标仍在，可通过托盘或快捷键呼出 |
| 单行横排 | 按钮只有一行时，设置与隐藏按钮横排显示 |
| 托盘隐藏悬浮条 | 右键托盘选择“隐藏悬浮条”，工具条隐藏且应用不退出 |
| 宽度保持 | 调整工具条宽度后，在设置页修改按钮显示/隐藏或排序，工具条宽度保持用户调整值，不恢复默认 |
| 调试日志 | 默认关闭；开启后运行事件写入本地日志文件，日志中不含被转换的文本 |
| 拖拽排序 | 设置页可在扁平列表中按住按钮拖到任意位置，松开后悬浮条顺序即时更新并持久化 |
| 快捷键冲突 | 注册被占用时设置页给出冲突提示，应用不崩溃 |
| 快捷方式呼入 | 应用运行时双击快捷方式，悬浮条直接呼出，不产生新实例 |
| 托盘 | 托盘左键呼出悬浮条；右键菜单可打开设置、退出 |
| 安装 | Windows NSIS / macOS DMG 安装后可正常启动，无运行时依赖报错 |
| 数据安全 | 使用后配置目录与日志中不含被转换的文本内容 |

## 11. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 部分应用不支持模拟粘贴（终端、密码框、特殊控件） | 降级为复制到剪贴板 + 气泡提示（3.2） |
| macOS 用户未授权辅助功能 | 启动/首次使用时引导，设置页显示权限状态（4.6） |
| 管理员权限应用无法注入（Windows） | 文档标注已知限制；用户需以管理员运行 StringCraft（3.2） |
| 高 DPI / 多显示器布局异常 | 逻辑像素 + 越界归位（F1.13、第 5 节） |
| WebView2 缺失（Windows 10 旧环境） | 安装包引导安装 Bootstrapper（第 5 节） |
| 剪贴板被其他程序并发改写 | 执行期间串行处理，操作前后快速读写，异常时恢复备份 |
